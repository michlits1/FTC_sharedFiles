BIOBUZZ AUTO PLANNER (FTC 2026-27)
==================================

A tool for practicing the part of engineering that happens before the code:
studying the field, choosing objectives, and planning a 30-second AUTO.
No Java needed. The team does all the planning; the tool only simulates it.

THE LOOP
1. STUDY    Print biobuzz_paper_set.pdf. Read the Field Sheet.
2. PLAN     On the Plan Sheet: goal, objectives (points and estimated seconds),
            order, risks. Sketch the route on the Field Sheet.
3. ROUTE    Write the route on the paper Route Sheet, one command per row.
4. PREDICT  Open biobuzz-planner.html. On the Prediction tab, enter expected
            points and seconds, then Lock.
5. ENTER    On the Program tab: pick the start tile and facing, enter your
            robot's real timings, and copy the Route Sheet row by row.
6. RUN      Press Run AUTO. Watch the Replay. Compare with your prediction.
7. REVISE   Go back to the paper first. Change the plan, not just the numbers.

WHAT IS SIMPLIFIED
Whole tiles and 90-degree turns, one red robot, aimed launches always go in.
FLOWER positions and the POLLEN needed to tip the HIVE are estimates.
The "Rules used" tab lists every assumption and the manual sources.

FILES
